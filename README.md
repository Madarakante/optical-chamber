# Optical Chamber

A circular optical chamber modelled in Autodesk Fusion 360, with a ring of internal baffles and three mounting tabs.

## Files

| File | Description |
| --- | --- |
| `optical chamber.step` | 3D model (STEP AP242, millimetres) |

## Notes

- Units: millimetres
- Bounding box: approx. **54 × 15 × 80 mm**
- Bodies: 1

Open the STEP file in any CAD package (Fusion 360, FreeCAD, SolidWorks, etc.) to view or edit it.
